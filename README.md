# Bibliography Extract

Extracts the References section from academic PDFs and displays it as a scrollable table in a side panel — so you can look up citation numbers without scrolling to the back of the paper.

## Usage

1. Open a PDF in Obsidian
2. Click the book icon in the ribbon, or run **Extract references from PDF** from the command palette
3. The References panel opens on the right with all `[N]` citations listed

**Click** any row to search for it on Google Scholar. **Right-click** to copy the reference text.

Extracted references are cached per file for the session, so switching between open PDFs is instant after the first extraction.

## Requirements

- Obsidian 1.7.2 or later
